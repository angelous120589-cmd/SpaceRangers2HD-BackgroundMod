FHD_FastNewGame Native v0.4 (ЭКСПЕРИМЕНТАЛЬНО)

УСТАНОВКА
1. Удалите ВСЕ старые папки FHD_FastNewGame (v0.2/v0.3).
2. Перенесите FHD_FastNewGame из архива в каталог Mods игры.
3. Необходим установленный XenoNativeLoader (в игре подхватывает *.XenoPlugin.dll).
4. Включите мод в игровом меню и создайте новую партию.

ЧТО УСКОРЯЕТСЯ
A. Подготовительная симуляция ВСЕГДА выполняет 300 полных ходов.
B. Расчётные функции TThreadCalc.Execute вызываются синхронно, без запуска
   и ожидания отдельного потока на каждом подготовительном дне.
C. Во время фазы подготовки галактики (стадия 6) отключается запись
   анимационного фильма для системы игрока. Все движения, бои, изменения
   NPC, задания и расчёт мира продолжают выполняться; записи анимации
   при обычной игре по-прежнему активны.
D. Через лог XenoNativeLoader при Profile=1 записывается время расчёта
   галактики и системы игрока каждые 100 ходов.

НАСТРОЙКИ: Native/FHD_FastNewGame.XenoPlugin.ini
SkipPregameFilm=1  -- отключить запись анимации ТОЛЬКО до начала партии
SkipPregameFilm=0  -- исходный режим записи анимации (рекомендуется для
                      проверки идентичности с обычной игрой)
Profile=1 -- записывать суммарное время этапов, Profile=0 -- не измерять

ОГРАНИЧЕНИЯ
Поддерживается только проверенная адресная карта игры SRHD 2.1.2500.
На другой версии плагин отказывается менять машинный код.
Реальный запуск и результат х2 должны быть проверены в самой игре.
Оптимизация записи фильма намеренно экспериментальна: отсутствие
изменений механики при одинаковом seed НЕ подтверждено сравнениями.
Не устанавливайте одновременно v0.2/v0.3.
Если есть вылет/различие состояния мира, выставьте SkipPregameFilm=0,
запустите новую партию с тем же seed и приложите log.
